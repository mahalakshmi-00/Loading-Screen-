# Loading-Screen
 # Loading Animation Example

This is a simple loading animation with styled text and a rotating loader, inspired by Slack's sidebar theme loading screen. The animation uses basic HTML and CSS.

## Features

- A rotating circular loader.
- Text displaying instructions for changing sidebar colors.
- Author text styled differently.
- Centered content with a clean layout.

## Demo

You can see the demo by opening the `index.html` file in a browser. The loading animation will appear with the following text:

**"For new sidebar colors, click your workspace name, then Preferences > Sidebar > Theme  
- Your friends at Slack"**

## Files

- `index.html`: The HTML structure of the page.
- `styles.css`: The CSS for styling the loading animation and text.

## How to Run

1. Clone or download this repository.
2. Open the `index.html` file in your browser.
3. The loading animation will appear with the styled text.

## Technologies Used

- **HTML**: For structure.
- **CSS**: For styling and animation.
